## Resumo
Para este trabalho foi necessário criar uma aplicação Python que permitisse ao utilizador usar as funcionalidades pedidas na ficha realizada na aula prática seis

Este programa carrega e guardar dados meteorológicos em ficheiros, permite consultar e apresentar uma tabela com os registos e realizar vários cálculos sobre as temperaturas e a precipitação e faz uma lista dos dias em que a precipitação foi superior a um limite definido pelo utilizador. Além disso, permite visualizar um gráfico com a evolução das temperaturas mínima e máxima e da pluviosidade.
