## Resumo
Desenvolver uma aplicação em Python para a gestão de alunos de uma turma, permitindo criar uma turma, inserir alunos com os respetivos dados e notas, listar todos os alunos e consultar um aluno através do seu ID. A aplicação permite ainda guardar e carregar os dados da turma através de ficheiros, mantendo um menu interativo até o utilizador escolher sair
