## Resumo
O objetivo deste trabalho era criar um programa em Python que apresenta um menu de opções e permite realizar várias operações sobre uma lista de números.

As regras consistem em:
- O programa deve guardar a lista numa variável interna.
- As opções 1 e 2 criam uma nova lista e sempre que uma nova lista é criada substitui a lista anterior.
- As opções 3 a 9 trabalham sobre a lista que está guardada naquele momento.
- Depois de executar uma operação, o menu deve voltar a aparecer.
- Quando o utilizador escolhe 0, o programa termina e apresenta a lista final.
